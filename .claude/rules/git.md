# Git Workflow

- Commit straight to `main`, one commit per working step. Never commit broken code.
- Conventional commits: `feat:`, `fix:`, `refactor:`, `docs:`, `style:`, `chore:`.
- Subject in imperative mood, max 60 chars, no trailing period.
- Never commit scratch docs (TODO, LEARNINGS, NOTES, AGENTS) unless explicitly asked — keep them in `.gitignore`.
- Update `README.md` in the same commit as the behaviour it documents.
